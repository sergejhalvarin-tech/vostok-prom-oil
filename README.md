# Oil_Shop — сайт промышленных масел

Одна страница, разделы в верхнем меню переключаются по хешу (`#shelf`, `#transport` …).
Сквозная идея: интерактивная 3D-история «путь нефти от скважины до масла», в конце — каталог и заявка.

Готово: **Этап 1. Добыча на шельфе** (`src/sections/shelf.js`): платформа, море со льдом, разрез до пласта
со скважинами, отгрузка на танкер, 7 шагов с подписями. Остальные разделы — заглушки (`src/sections/stub.js`).

## Команды

    npm install
    npm run dev          # http://localhost:5180, пересборка на лету
    npm run build        # dist/ — статический сайт для GitHub Pages
    npm run model:shelf  # пересжать модель платформы из models/source/ (не в git)
